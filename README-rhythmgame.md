# Rhythm Game

Pythonとpygameで制作したリズムゲームです。落ちてくるノーツを判定ラインに合わせてクリックし、スコアを競います。

## デモ

> スクリーンショットや動画GIFをここに貼る

## 機能

- **2つのモード**: 音楽ファイル不要のデモモードと、MP3/WAV/OGGに対応した音楽モード
- **4段階の判定**: PERFECT / GREAT / GOOD / OK（判定ラインとのズレで自動判定）
- **コンボボーナス**: コンボ数に応じてスコアが加算
- **30秒制限**: タイムアタック形式でゲームオーバー後にスコアと最大コンボを表示
- **残り時間警告**: 残り5秒以下で赤色表示

## 操作方法

| 操作 | 内容 |
|------|------|
| `SPACE` | デモモードで開始 |
| `M` | 音楽ファイルを読み込んでゲーム開始 |
| マウスクリック | ノーツを叩く |
| `ESC` | 終了 |

## 実装のこだわり

- ノーツが判定ラインに到達するタイミングから逆算して生成タイミングを計算し、ズレのない演出を実現
- ループ中のリスト操作によるバグを防ぐため、コピーを使ったイテレーション処理
- `pygame.mixer` の初期化パラメータを明示的に指定し、環境差による音声の不安定さを抑制

## 動作環境

- Python 3.x
- pygame

## インストールと起動

```bash
pip install pygame
python game.py
```

音楽モードで使う場合は、MP3・WAV・OGGのいずれかのファイルをスクリプトと同じディレクトリに置いてから `M` キーで起動してください。
